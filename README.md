# Beatlot motion (HyperFrames)

Three compositions for the Beatlot showroom Reels studio, written in beats (126 BPM):

- `comps/promo` 9:16, 19.05 s (40 beats): raw clips in, the chat line, beat-cut assembly, gold flash on the drop (beat 20), end card. EN + DE.
- `comps/loop` 1:1, 7.62 s (16 beats): seamless loop for the site hero / OG.
- `comps/explainer` 16:9, 30.48 s (64 beats = 16 bars): the three messages, the brand kit, pricing. EN + DE.

Rendered silent on GitHub Actions (`.github/workflows/render.yml`); the music (a Setavaz track) is added afterwards, outside this public repo.
Car frames: real Reels made by our engine for a pilot showroom. Dealer names and logos are samples.
